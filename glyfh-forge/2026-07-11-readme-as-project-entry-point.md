# READMEは入口である

`README.md` は、コードを読む前の入口になる。

今回の glyph-forge では、もともと README が短い説明だけだった。
そこで、最初に知りたいことを上から順に置いた。

- 何を作るプロジェクトか
- どんな技術を使っているか
- どうセットアップするか
- どう画像を作るか
- API は何を受け取るか

特に大事なのは、`frame_text`、`inner_text`、`outer_text` の関係を書くことだった。

このプロジェクトでは `frame_text` が形を作り、`inner_text` が内側を埋め、`outer_text` が外側を埋める。
ここが分かると、コードを読む前に画像生成の考え方がつかみやすくなる。

README は詳しすぎても読まれない。
でも、動かすまでに必要な道は置いておきたい。
今回はそのバランスを狙った。

# 画像をフレームとして使うAPIを追加した

文字から画像を作る処理に加えて、画像そのものをフレームとして使うAPIを追加しました。

これまでは `frame_text` を文字列として渡し、その文字の形をもとに `inner_text` と `outer_text` を配置していました。

今回追加したのは、アップロードされた画像を読み込み、その明暗から形を作る処理です。

## 追加したAPI

追加したエンドポイントは `POST /images/frame-file` です。

`multipart/form-data` で画像ファイルを受け取り、画像の暗い部分を内側、明るい部分を外側として扱います。

内側には `inner_text`、外側には `outer_text` を配置します。

## 実装の考え方

既存の画像しきい値変換を再利用しました。

画像をグレースケール化し、平均値をしきい値として2値化します。

その2値グリッドを、既存の `binary_grid_to_text_grid` に渡すことで、画像由来の形をテキストグリッドへ変換できます。

つまり、新しいAPIの中心は「アップロード画像を既存の2値グリッド形式に寄せる」ことです。

## テストしたこと

サービス層では、黒いピクセル側に `inner_text` の色が出ること、白いピクセル側に `outer_text` の色が出ることを確認しました。

API層では、画像ファイルをアップロードするとPNGが返ることを確認しました。

また、不正なファイルを渡した場合は `422` を返すようにしました。

## 使ってみた感想

入力画像をそのまま1ピクセル1文字として扱うと、出力が大きくなりすぎます。

そのため、実際に試すときは入力画像を適度に縮小してから描画すると扱いやすくなります。

画像を先に小さくするだけで、文字アートとしての密度が調整しやすくなります。

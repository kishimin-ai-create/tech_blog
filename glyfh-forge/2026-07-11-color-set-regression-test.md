# 色の混入は色集合で見る

## はじめに

画像の回帰テストでは、「だいたい指定色に見える」だけを見ると危ない。

中間色や黒が混ざっていても見逃すことがある。

## 使った考え方

生成画像の色集合を取り出して、許可した色だけかを見る。

今回なら、基本は次の色だけになる。

- 背景色
- `inner_color`
- `outer_color`

## 何が嬉しいか

`frame_text` の黒文字が混ざったときに気づける。

`outer_color` が `inner_text` 側へ侵食したときにも気づきやすい。

## まとめ

`outer_color` が `inner_text` 側へ侵食したときにも気づきやすい。

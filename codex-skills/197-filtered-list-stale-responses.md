# 一覧の取得元が変わったときに古い結果を表示しない

非同期の一覧取得では、先に始めた処理の結果が後から到着することがある。管理画面が別の取得元に切り替わった後に、前の結果を表示し続けると、利用者が現在のデータと誤認する。

## 対応

profile-hub の [PR #134](https://github.com/kishimin-ai-create/profile-hub/pull/134) では、結果と取得関数を対応付けた。現在の取得元と結果の取得元が異なる場合は読み込み中を表示し、effect の後始末後に届いた結果は状態へ反映しない。

作品には Engineering または Hobby のセクションを表示し、取得済みの一覧から選択したセクションを絞り込む。空と取得失敗はそれぞれ別に表示する。

## 検証と範囲

コンポーネントテストは一覧の絞り込み、空、失敗、取得元が変わった際に古い結果が消えることを確認した。MSW を使った接続テストは認証ヘッダーと API レスポンスの表示を確認した。

これはブラウザーと本番 API の接続を実測したものではない。作品の作成・編集・削除・並べ替え操作はこの PR の対象外であり、下書き中の API と合わせてもプロジェクト全体の完成を意味しない。

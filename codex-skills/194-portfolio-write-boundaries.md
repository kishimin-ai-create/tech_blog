# Portfolio 作成 API で入力サイズと URL を検証する

管理者が登録した Portfolio は公開ページに表示される。認証された入力であっても、後でリンクとして描画される URL と、処理する本文の大きさは API で検証する必要がある。

## 実装した境界

profile-hub の [PR #127](https://github.com/kishimin-ai-create/profile-hub/pull/127) は、section、名前、概要、技術一覧、表示順と任意 URL のスキーマを追加した。URL は構文を検証したうえで `http:` と `https:` に限定する。名前や一覧には上限を設けたが、その具体的な値は製品要件として確定したものではなく、レビュー対象である。

[PR #128](https://github.com/kishimin-ai-create/profile-hub/pull/128) は、認証ガードの後に作成処理を置き、本文を 64 KiB に制限してから JSON とスキーマを検証する。成功時に保存した公開フィールドを返し、不正な URL、不正 JSON、過大本文は保存しない。

## 検証と未確認事項

Small テストで未認証、不正 URL、不正 JSON、過大本文と正常作成を確認した。PostgreSQL へ保存し公開一覧に現れることを確認する Medium テストも追加したが、執筆時点でその PR の CI は待機中だった。

DB テストをローカルで実行できず、全体カバレッジも閾値未達である。これらは下書き PR 上の実装であり、マージや本番公開を意味しない。編集・削除・並べ替えにも同じ検証境界を適用する必要がある。

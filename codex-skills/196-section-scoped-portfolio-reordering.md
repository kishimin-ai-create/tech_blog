# 並べ替えをセクション内の全件更新として扱う

Engineering と Hobby の作品は同じ Portfolio テーブルにあるが、表示順はセクションごとに独立している。[PR #132](https://github.com/kishimin-ai-create/profile-hub/pull/132) では、管理者が指定したセクションの全 ID を並べ替える API を追加した。

## 更新の境界

入力はセクションと重複しない ID の配列で、最大500件に制限する。対象セクションの行をロックして現在の ID 集合と比較し、不足、重複、別セクションの ID があれば変更しない。各更新の条件にもセクションと ID の両方を含め、処理を serializable トランザクションに置いた。

## 検証と残る課題

Small テストは認証、不正なセクション、重複 ID、範囲外 ID、欠落と正常要求を確認した。実 PostgreSQL で片方を並べ替え、もう片方の順序が変わらないことを検証するテストも追加したが、執筆時点では CI 実行中である。

同時更新によるトランザクション競合の再試行は実装していない。ID 数の上限と要求形式は画面側との調整が必要であり、下書き PR の作成はマージや本番公開を意味しない。

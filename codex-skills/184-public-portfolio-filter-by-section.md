# 公開ポートフォリオをセクションごとに取得する

HobbyとEngineeringの公開ページは、それぞれ自分のセクションに属するポートフォリオを表示する。公開APIでは `section` を必須にし、DBクエリで対象を絞って返す。

[PR #68](https://github.com/kishimin-ai-create/profile-hub/pull/68) のテストは両セクションの取得に加え、パラメータの欠落や不正な値を確認している。順序は表示順とIDで決定し、同じ表示順のレコードも安定して並ぶ。URLが登録されていない項目はnullとして返す。

ブラウザで一覧を受け取ってから振り分けるのではなく、取得条件をAPIの契約に含めることで、呼び出し側が対象を明示できる。現状は全件を返す設計であり、ページネーションの実装や大量データでの性能は確認していない。

画面間の導線については[セクション別ナビゲーションの記事](./173-section-owned-navigation-and-heroes.md)を参照。APIの絞り込みと、HobbyとEngineeringを直接行き来しない画面仕様は別々に確認する。

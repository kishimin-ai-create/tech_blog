# Home のリンク名を表示文言と揃える

## 背景

profile-hub の Home には Engineering と Hobby の入口がある。リンクには「Engineering を見る →」のような文言を表示していたが、`aria-label` がアクセシブルネームを「Engineering」に上書きしていた。表示を見て文言を読み上げる音声操作では、画面上の文言と操作対象の名前が食い違う可能性がある。

## 対応

両リンクの `aria-label` を外し、リンク内の表示テキストをそのままアクセシブルネームとして使うようにした。リンク先と画面に見える文言は変えていない。テストでは両リンクを表示文言の名前で取得し、キーボード操作を含む既存のブラウザーテストも同じ名前で操作する。

## 検証と限界

変更前に表示文言の名前を期待するテストが失敗し、修正後に成功した。公開画面の56テスト、Chromium と WebKit の通常ブラウザーテスト28件、およびメモリーデータを使う API 経由のブラウザーテスト4件が成功し、[統合 CI](https://github.com/kishimin-ai-create/profile-hub/actions/runs/41550876341) の全5ジョブも成功した。音声認識ソフトによる実機操作や、画面全体のアクセシビリティ監査は実施していない。

可視テキストだけで目的が分かるリンクでは、別の名前を上書きする必要がないかを先に確認すると、表示とアクセシブルネームの不一致を避けやすい。

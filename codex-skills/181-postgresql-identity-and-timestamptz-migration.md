# PostgreSQLへの変更でIDと日時の扱いを揃える

ユーザーの指定により、profile-hubのデータベースはPostgreSQLを採用した。テーブル追加では型名を置き換えるだけでなく、IDの生成方法と日時が表す意味を合わせる必要があった。

IDには符号付きのBIGINTと `GENERATED BY DEFAULT AS IDENTITY` を使い、瞬間を表す日時には `timestamptz` を使う方針にした。アプリケーション側では日時をUTCの瞬間として扱う。これは実装上の決定であり、ユーザーが細かな型まで指定したという意味ではない。

最初のSkillテーブルはDrizzleのスキーマとマイグレーションを一緒に追加した。PostgreSQLの実データベースでマイグレーションとテーブルのテストを実行し、後続のテーブルにも同じ方針を適用した。テスト用DBでの確認であり、本番環境の移行完了を示すものではない。

[Issue #6](https://github.com/kishimin-ai-create/profile-hub/issues/6) と [PR #58](https://github.com/kishimin-ai-create/profile-hub/pull/58) に変更の背景と差分がある。PRは執筆時点で未マージ。既存データを持つ環境への移行では、型変換とデータの検証を別途計画する必要がある。

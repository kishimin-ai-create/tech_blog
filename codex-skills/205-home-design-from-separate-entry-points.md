# 2つのセクションを混ぜない Home を下書きする

## 背景

profile-hub は Engineering と Hobby を別の公開体験として扱う。各セクションには独自のヒーローがあるが、両方への入口となる Home の専用デザインはなかった。片方のヒーローを流用すると、そのセクションの文脈が Home 全体に入り込む。

## 対応

既存 Figma のヘッダー、フッター、カードの外観を参考に、編集可能な Home のデスクトップ・モバイル下書きを作成した。名前、肩書き、紹介文の後に Engineering と Hobby のカードを別々に置く。名前と肩書きはダミーであり、デザインレビューは完了していない。確認時、ファイル内のローカルコンポーネントとスタイル・変数は空だったため、既存のフレーム要素を複製して使用した。

実装では各カードに説明文と独立したリンクを置き、画面幅が狭い場合は縦に並べた。ページ名の見出しは支援技術向けに残し、プロフィール名を視覚的に大きく表示する。

## 検証と限界

固定 API 応答を使って Chromium で1280px・375pxの表示を確認し、横方向にはみ出していないことを確かめた。公開画面の53テストと、Chromium・WebKit のナビゲーション等20テストが成功した。実データでの外観、支援技術による確認、最終デザインの承認は未実施である。

## 学び

複数の体験の入口では、共有できるヘッダーやカードを使いながら、各体験の専用ヒーローと入口ページを分けると、情報の境界を保ちやすい。Figma の下書きと実装を比べる際は、画面サイズ、固定データ、未確認の実データを分けて記録する。

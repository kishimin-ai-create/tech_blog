# 管理画面の取得エラーから再試行する

## 背景

profile-hub の管理画面では、保存済みリンクを取得して編集する。取得に失敗するとエラーは表示されていたが、その画面には再試行する操作がなく、一時的な通信障害の後もページを読み直す必要があった。

## 対応

エラー表示に再試行ボタンを追加した。操作後は読み込み中に戻り、同じリンクを再取得する。読み込み結果は既存の状態管理を通し、リンクの保存や認証更新の動作は変更していない。

回帰テストでは、最初の取得を失敗させ、再試行後にデータを返す。修正前は再試行ボタンを見つけられず失敗し、修正後は編集フォームに元の URL が表示された。

## 検証と限界

対象テスト、管理画面の118テスト、整形、型チェック、Lint、HTML 検査、ビルドが成功した。[統合 CI](https://github.com/kishimin-ai-create/profile-hub/actions/runs/41558199899) も全5ジョブ成功した。テストは通信をテスト用サーバーで再現しており、本番環境での通信障害を実演したものではない。[PR #218](https://github.com/kishimin-ai-create/profile-hub/pull/218) はドラフトで、main には未統合である。

同じ操作が必要だったリンク一覧にも、別の [PR #219](https://github.com/kishimin-ai-create/profile-hub/pull/219) で再試行を追加した。失敗後に一覧へ戻るテストを用意し、管理画面全体の119テスト、整形、型チェック、Lint、HTML 検査、ビルドが成功した。[統合 CI](https://github.com/kishimin-ai-create/profile-hub/actions/runs/41558565187) も全5ジョブ成功した。

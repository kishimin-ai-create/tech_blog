# Biome 2.0.6でpresetキーが原因になった設定エラー

## 結論

`linter.rules.preset` は今回使用したBiome 2.0.6で未対応だった。該当キーを削除すると設定を読み込めるようになった。根拠は `d7d6816`、`a9b6076` と実行出力である。

## 発生した問題

Windowsの `app/backend` で `bun run code` を実行すると、コード検査の前に停止した。

```text
Found an unknown key `preset`.
```

該当箇所は `"preset": "recommended"`。この状態では整形やLintを実行できなかった。

## 調査

CLIの出力が設定ファイルの18行目を直接指した。実行コマンドをCIから直接呼ぶ形へ変更した時も、同じ設定エラーが残った。呼び出し方を変えても設定内容は変わらないため、この変更だけでは解決しなかった。

## 原因

FACT: インストール済みBiomeが `preset` を不明なキーとして拒否した。今回の結果を別バージョンへ一般化しない。

## 解決方法

`biome.json` から該当キーを削除した。既存のstyleルールは維持した。続いてテストファイルの整形とimport順序を既存コマンドで修正した。

```sh
bun run code:fix
bun run code
```

## 動作確認

10月6日の修正後と10月7日の再確認で、`bun run code` は成功した。再確認では5ファイルを検査し、修正は行われなかった。

## 再発防止

PROPOSAL: 設定追加時は導入済みバージョンのCLIで読み込み確認する。CIは現在 `bun code:fix` を実行する設定であり、変更を拒否する検査だけの構成ではない。GitHub上の最新実行結果は本記事では確認していない。

## まとめ

設定の読み込み失敗とソースコードのLint違反を分ける。まずCLIが直接示した設定エラーを確認し、その後にコード検査の結果を評価する。

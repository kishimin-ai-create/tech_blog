# 生成画像の名前に日時とランダム値を併用する

## はじめに

生成画像を複数回保存するとき、時刻だけの名前は生成時期を読み取りやすいが、同じ秒の実行で名前が重なる可能性がある。ランダム値だけでは区別しやすくても、一覧から生成時期を把握しにくい。実装では両方を組み合わせた。

## 実装

ローカル日時を文字列化し、ランダムなトークンとPNG拡張子を連結する。

```python
timestamp = datetime.now().astimezone().strftime("%Y%m%d_%H%M%S")
token = secrets.token_urlsafe(token_bytes)
filename = f"{timestamp}_{token}.png"
```

日時は人が見たときの手掛かり、トークンは同じ秒の名前の重複を起こしにくくするための値である。「必ず重複しない」ことは、この実装やテストでは証明していない。

## 動作確認

日時とトークンを固定したテストで、保存先へ渡したファイル名の形式を確認した。画像の保存処理が呼ばれることは確認したが、同時実行時の衝突率や、生成された画像の見た目は測定していない。

## 学び

ファイル名の可読性と衝突しにくさは別の目的として扱う。日時は時刻情報、ランダム値は重複リスクの低減を担う。固定時刻のテストは形式を決定的に確認できるが、運用時の一意性を保証するものではない。
